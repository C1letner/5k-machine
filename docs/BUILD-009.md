# Build 009 — Development Director

The development organization now uses durable work orders instead of a vague recurring instruction.

Lifecycle:
BACKLOG -> CLAIMED -> IMPLEMENTING -> TESTING -> COMMITTED -> VERIFIED
or BLOCKED.

A task is not complete because an agent discussed it. Completion requires evidence:
- commit SHA for code changes,
- test evidence,
- or an explicit human-gated blocker.

Initial backlog:
- DEV-009 Command Center reliability
- DEV-010 World Intelligence architecture
- DEV-011 Regime Agent
- DEV-012 Pipeline integration

Global prohibitions remain: no real trading, no capital-firewall changes, no spending, no secret rotation/exposure, no destructive database/infrastructure actions.
