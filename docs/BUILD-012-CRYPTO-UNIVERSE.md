# Build 012 — Crypto Universe + Relationship Matrix

Initial liquid crypto universe: BTC, ETH, XRP, SOL, ADA, DOGE, AVAX, LINK.

The universe sensor fetches public USD spot observations. The relationship matrix evaluates every ordered pair through the Anomaly Scanner and ranks only unusual leader/follower underreaction events.

8 assets produce 56 directed relationships per scan before additional windows/features are added.

Anomaly != alpha. Matrix hits become inputs to the Hypothesis Factory; they never authorize trades.

The universe is configuration, not architecture. It can expand as data quality, liquidity filters and testing capacity mature.
