# Build 024 — Independent Auditor Operating System

Independent Auditor reports only to Owner.

V1 independently reconciles:
- management claims that trading authority is OFF,
- sensitive decisions requiring Owner approval,
- executive COMPLETE claims against evidence,
- transaction ledger against zero trading authority,
- forward-survivor counts against passed experiments,
- runtime failures and research backlog.

Outputs: CLEAN / EXCEPTIONS / MATERIAL_FAILURE.

HIGH or CRITICAL findings require Owner attention and are never routed through CEO for suppression.

Auditor has no portfolio or management authority. Its purpose is truth, evidence, and control assurance.
