# Research Program Stopping Rule — Draft for Owner Approval

Purpose: prevent endless sensor/data expansion from redefining repeated null results as progress.

No numeric threshold is activated without Owner approval.

A final rule should specify:
1. maximum additional research spend before review;
2. maximum number of genuinely independent information dimensions to test;
3. minimum forward-validation standard;
4. time horizon for the research program;
5. mandatory pause/redesign condition if no forward survivor exists.

Current recommendation: do not buy new paid data until a specific preregistered experiment requires it.
